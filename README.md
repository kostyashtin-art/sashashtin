# Наш малыш ♡

Семейный PWA-дневник движений малыша для GitHub Pages + Supabase.

## Файлы
- `index.html` — приложение и дизайн
- `config.js` — подключение Supabase
- `manifest.json` — PWA
- `sw.js` — service worker
- `icon.svg` — иконка
- `supabase.sql` — SQL-схема из предыдущей версии проекта
